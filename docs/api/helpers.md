# Helper functions

!!! tip "What is the model module?"
    The `helper functions` provides a simple way to deal with recurrent GeoData conversions.
    Meanwhile, we recommend to look through the [`Example`'s helpers](../copy_of_examples/5-helpers/helper_functions/) for a more hands-on introduction about
    the model module and its usage.
